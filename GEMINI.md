## Project Overview

This is a simple Java project managed with Gradle. The main entry point is the `org.example.Main` class, which prints a welcome message and a loop counter. The project uses JUnit 5 for testing.

## Building and Running

*   **Build the project:**
    ```bash
    ./gradlew build
    ```
*   **Run the application:**
    ```bash
    ./gradlew run
    ```
*   **Run the tests:**
    ```bash
    ./gradlew test
    ```

## Development Conventions

*   The project follows the standard Java project structure.
*   Dependencies are managed in the `build.gradle` file.
*   Tests are located in the `src/test/java` directory.
